# Pediatric Health Research System

A full-stack application designed to analyze and visualize the impact of maternal education on child health outcomes. Built for a health research project.

## Tech Stack
- Frontend: React.js (Vite), Tailwind CSS, Recharts, Axios, React Router, Lucide-React
- Backend: Node.js, Express.js, Mongoose/MongoDB, JSONWebToken, Bcrypt.js

## Prerequisites
- Node.js (v18+)
- MongoDB running locally on port 27017

## Setup Instructions

### 1. Backend Setup
1. Open a terminal and navigate to the `backend` folder:
   ```bash
   cd backend
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Seed the sample research data. This will create an admin user and populate fake pediatric records:
   ```bash
   node seed.js
   ```
   *The admin user will be created with email: `admin@greennetspark.in` and password: `Admin@123`.*
4. Start the backend server:
   ```bash
   node server.js
   ```

### 2. Frontend Setup
1. Open a new terminal and navigate to the `frontend` folder:
   ```bash
   cd frontend
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the Vite development server:
   ```bash
   npm run dev
   ```

### 3. Usage
- Go to the frontend URL (typically `http://localhost:5173`).
- Log in using the credentials generated by the seeder script.
- View the comprehensive analytics dashboard showing charts mapping maternal education to health scores, vaccination rates, and illness frequency.
- The system automatically calculates health scores (0-100) based on vaccinations, nutrition, hygiene, and disease tracking.
- Add new records and watch the insights regenerate in real-time.

## UI/UX Note
The interface is designed with a clean, medical aesthetic leveraging specific color tokens and modern visual components to present pediatric data effectively.
